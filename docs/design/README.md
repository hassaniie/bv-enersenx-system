# Design foundations

- [references.md](./references.md): Mobbin references per flow, and what we take or avoid.
- [principles.md](./principles.md): the rulebook (money model, trust, UX laws, content, accessibility) and the checklist.
- [ux-review.md](./ux-review.md): issues found in the MVP, with severity, fix and status.
- [redesign-proposal.md](./redesign-proposal.md): the proposed changes, waiting for approval.

## Standing rule for every new flow

1. **Before building:** add the flow's Mobbin references to references.md (saved to the
   "EnerSenX MVP" collection), list the principles it must satisfy, and list its edge cases.
2. **After building:** run the checklist in principles.md and report each rule as pass or
   fail. A flow isn't done until it passes.
3. Keep references.md, principles.md and ux-review.md up to date in the same change.

Mobbin shows patterns; ReUI (AGENTS.md) decides the look. Never copy another app's visual style.
